# Changelog

## v0.1.0-rc1 (2026-11-21)

Release commit: RELEASE_SHA_PENDING

- TOML contract format for one agent graph edge: required fields, types, enums, length limits, list sizes, ID references into the producer's input context, unknown field policy and named semantic checks.
- `check(edge, message, context)` returns a result with violations and field paths.
- `guard` decorator with stop mode (raises `HandoffBlocked`) and warn mode.
- pytest plugin through the `pytest11` entry point with the `handoff_pact` fixture. It catches producer drift, consumer crashes and consumer drift.
- Sample pipeline of four agents with a scripted model and an invented policy corpus.
- Fault injector with seven fault types.
- Benchmark: detection per fault type with Wilson intervals, false alarms on clean runs, blast radius with and without contracts.
- Docs generator: one page per contract and a mermaid graph.
- README numbers, the results page and the social preview are generated by scripts.
